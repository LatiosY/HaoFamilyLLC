# Hao Family Investment LLC

Static bilingual (EN / 中文) brochure site for Zhixin Hao. Next.js App Router, Tailwind, Vercel.

```bash
npm run dev
```

- English: `/`, `/buy`, `/sell`, `/contact`
- Chinese: `/zh`, `/zh/buy`, `/zh/sell`, `/zh/contact`

Company reference files go in `private/` (gitignored). Put only approved public assets in `public/` or `src/`.
